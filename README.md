# 스시 루프 (Sushi Loop)

생선을 등에 한가득 쌓아 나르고, 회전 벨트에 딱 맞는 초밥을 올려 손님을 사로잡는 3D 회전초밥집 경영 게임.

플레이: https://kh32-7.github.io/sushi-loop/

## 원작 조합과 비튼 포인트

- **Pizza Ready! (Supercent)** 의 아이들 아케이드 식당 경영 루프를 뼈대로 삼음. 쿼터뷰 카메라, 화면 어디든 드래그하는 플로팅 조이스틱, 버튼 없이 "밟으면 동작"하는 발판, 등에 탑처럼 흔들리며 쌓이는 스택, 돈 더미 흡수, 초록 해금 발판, 직원 고용, 업그레이드 방, 식당 이전 구조를 그대로 가져옴.
- 여기에 2026년 하이브리드 캐주얼 트렌드인 **컨베이어 벨트 퍼즐(Pixel Flow 류)** 을 결합함.
  - 벨트 슬롯 수가 한정되어 있어서 아무 접시나 막 올리면 벨트가 꽉 차서 새 접시를 못 올림. 손님 머리 위 말풍선과 상단 주문판을 보고 원하는 메뉴를 골라 올려야 효율이 남.
  - 벨트에서 3바퀴 넘게 안 팔린 접시는 말라서 회색이 되고, 방치하면 손님 인내심이 더 빨리 닳음. 수거함 발판에 서서 치워야 함.
  - 빈 접시는 설거지대를 거쳐야 다시 조리에 쓸 수 있어서 접시가 병목 자원이 됨.
  - 분기 레버를 해금하면 두 번째 벨트 루프와 투입구가 열려 레이아웃이 성장함.
  - 주문이 뜨자마자 원하는 접시가 도착하면 콤보가 쌓이고 팁 배수가 오름. 러시 타임에는 같은 메뉴를 대량 주문하는 단체 손님, 세트 3종을 순서대로 먹어야 하는 VIP(팁 3배)가 등장함.
  - 같은 메뉴를 3개 연속으로 올리면 세트 보너스(그 접시들 팁 +30%)가 붙어 배치를 고민하게 됨.
  - 투입구 발판에 빈손으로 서 있으면 수요보다 남는 신선한 접시를 벨트에서 다시 회수할 수 있음.
  - 손님 만족도(하트 게이지)가 식당 별점이 되고, 별점이 손님 유입 속도를 결정함. 별점이 3.5 아래로 떨어져도 손님은 계속 오고 팁만 줄어서 악순환에 빠지지 않음.

## 조작법

- 화면 아무 곳이나 누르고 드래그: 셰프 이동 (플로팅 조이스틱). PC에서는 마우스 드래그 또는 WASD/방향키.
- 모든 행동은 발판을 밟으면 자동으로 일어남.
  - 부두 상자: 재료 쌓기 / 파란 발판: 조리대에 재료 넣기 / 노란 발판: 완성 접시 들기
  - 벨트 투입구(화살표 발판): 접시를 벨트에 올리기 / 수거함 발판: 마른 접시 치우기
  - 좌석 옆: 돈과 빈 접시 챙기기 / 설거지대: 빈 접시 씻기
  - 초록 발판: 서 있으면 돈이 빨려 들어가며 새 시설 해금 / 보라 책상 앞 노란 발판: 업그레이드

## 핵심 시스템

- **식당 5곳**: 골목 포장마차 → 쇼핑몰 푸드코트 → 바닷가 스시바 → 고급 료칸 → 우주 정거장. 식당마다 테마, 벨트 수와 간격, 엇갈림, 좌우 반전, 메뉴, 대표 소품이 다름. 모든 시설을 열면 다음 식당으로 이전하고 이전 식당의 수익 기록이 남음.
- **식당별 기믹**: 쇼핑몰은 에스컬레이터로 손님이 한꺼번에 올라옴, 바닷가는 큰 파도가 치면 벨트가 7초간 빨라짐, 료칸은 코스 3접시를 순서대로 먹는 오마카세 손님(팁 1.5배), 우주 정거장은 무중력으로 접시가 떠다니며 5바퀴까지 마르지 않음.
- **영구 강화와 시즌**: 진주로 모든 식당에 적용되는 팁 +5%, 시작 적재량 +1, 자리 비운 수익 상한 +30분, 손님 인내심 강화를 삼. 우주 정거장까지 완성하면 수익 배율이 오른 다음 시즌(프레스티지)에 도전 가능.
- **메뉴 10종**: 연어, 달걀, 참치, 새우튀김, 우동, 성게 군함, 장어, 딸기 모찌, 연어알 군함, 은하 젤리. 메뉴마다 접시 색이 다름.
- **직원**: 운반 직원(수요 있는 접시를 벨트에 올리고 빈 접시와 마른 접시를 치움), 조리 직원(부두에서 재료를 날라 조리대를 채움).
- **업그레이드**: 이동 속도(+12%), 적재량(+3), 조리 속도, 벨트 속도, 접시 추가, 직원 속도, 직원 적재량. 최근 병목(접시 부족, 적재 가득, 조리 대기, 손님 대기)을 보고 "추천" 태그를 붙임.
- **장기 진행**: 오프라인 수익(최대 2시간, 하루 1회 무료 2배), 일일 미션 3개(자정 갱신), 7일 출석 달력, 업적 22개, 통계, 셰프 모자/앞치마와 인테리어 스킨 컬렉션(진주로 구매), 레시피 도감.
- **저장**: localStorage 자동 저장(5초 주기 + 화면 전환/종료 시). 저장 버전 필드와 마이그레이션, 손상 데이터는 백업 후 안전하게 초기화함.
- **연출**: 해금 시 카메라가 새 시설로 날아가 줌인했다가 복귀, 좌석의 지폐 더미가 금액만큼 층층이 쌓이고 밟으면 한 장씩 빨려 들어옴(동전 피치 상승), 흔들리는 스택과 받을 때 스쿼시, 아이템 포물선 비행, 해금 시 바운스 팝업과 색종이, 동전 흡수 궤적, 콤보 팁 팝업, 손님 이모지 반응, 러시 배너, 식당 이전 시 노렌 커튼 전환, 결과 화면 숫자 카운트업과 보상 진주 비행, 미션/업적/출석 보상 수령 비행.
- **온보딩**: 첫 실행 튜토리얼이 드래그 손 제스처, 목표를 톡톡 가리키는 손가락, 3D 화살표, 화면 밖 목표 방향 화살표로 순서대로 안내함. 이후에도 멈춰 있으면 다음 할 일(병목)을 화살표로 알려주고, HUD 에 다음 해금 목표와 비용을 표시함.
- **손님 흐름**: 좌석이 꽉 차면 입구에 줄을 서고, 오래 기다리면 화내며 떠남. 좌석이 늘수록 손님이 더 자주 옴.
- **UI**: 상단 HUD는 돈, 진행 바, 다음 목표와 별점 한 줄, 주문판으로 가볍게 구성하고 메뉴(미션, 출석, 영구 강화, 도감, 코스튬, 업적, 소리)는 오른쪽 위 햄버거 버튼 하나에 알림 점과 함께 접어 둠. 월드 라벨이 HUD와 겹치면 흐리게 처리함. 발판은 종류별 원색 판(상자 노랑, 조리대 파랑, 완성 접시 보라, 투입구 초록, 수거함 빨강)에 큰 아이콘을 넣고, 할 일이 있을 때만 맥동하며, 서 있는 동안 발밑에 원형 적재 게이지가 뜸.
- **사운드**: 식당마다 음계, 템포, 악기가 다른 절차적 BGM(골목 미야코부시 코토 로파이, 쇼핑몰 110BPM 밝은 신스, 바닷가 우쿨렐레풍 플럭, 료칸 히라조시 코토와 북, 우주 아르페지오와 패드). 16마디 A/B 구성, 러시 타임에는 템포 +15%와 타이코 레이어, 해금과 VIP 때 BGM 덕킹, 컨볼버 리버브, 적재/동전/발걸음 피치 랜덤. WebAudio 합성 효과음(발걸음, 적재 틱, 벨트 루프, 접시 달그락, 피치가 오르는 동전 연타, 해금 팡파레, 손님 반응)과 일본풍 펜타토닉 로파이 절차적 BGM. 폰 스피커 기준 믹스(마스터 피크 약 -3dBFS, 주요 효과음 RMS -24~-20dB, 베이스와 킥에 250~800Hz 배음 레이어, BGM 150Hz 이하 에너지 60% 이하)를 스모크 테스트에서 OfflineAudioContext 로 계측함. 일시정지 메뉴와 백그라운드에서는 BGM 이 멈춤.
- **성능**: 접시, 재료, 손님, 직원, 의자, 동전, 파티클, 행동 발판(아틀라스 텍스처)은 모두 InstancedMesh. 해금된 시설은 팝업 애니메이션이 끝나면 하나의 지오메트리로 병합해서 드로우콜이 식당 전체 해금 상태에서도 약 45회 수준. 식당 이전 시 지오메트리와 텍스처를 정리함. 느린 기기에서는 자동으로 그림자를 끄고 원형 그림자로 전환함.

## 실행과 빌드

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 생성
npm run preview  # 빌드 결과 미리보기
npm run build && node scripts/smoke.mjs   # 실제 터치 입력 스모크 테스트 (스크린샷은 shots/)
```

밸런스 봇: `node scripts/balance-bot.mjs` (STAGE=0~4, MIN=게임 시간 분). 게임 안에서 조이스틱 입력을 흉내 내는 탐욕 봇이 발판만 밟아서 영업하며 해금 시점과 분당 수익을 출력함. 1호점 기준 첫 해금 약 40초, 5분 안에 해금 6개 안팎, 직원 고용 이후 수익이 가파르게 오르도록 조정함.

디버그 옵션: `?debug` 를 붙이면 돈 추가, 5배속, 전체 해금, 러시 즉시 발생, 오프라인 수익 테스트, 진주 추가 버튼이 나타남.

## 기술

- Vite + 바닐라 JavaScript(ES modules) + three.js. 외부 이미지, 폰트, CDN 없이 지오메트리와 캔버스 텍스처로 모든 그래픽을 절차적으로 생성함.
- 모듈: `game.js`(시뮬레이션), `belt.js`(벨트 경로와 슬롯), `nav.js`(충돌과 길찾기), `world.js`(환경과 발판), `models.js`(모델), `ui.js`(HUD와 패널), `meta.js`(미션, 업적, 출석), `audio.js`, `input.js`, `save.js`, 밸런스 수치는 `config.js` 에 모음.
