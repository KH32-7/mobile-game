# 블록 조커 (Block Joker)

8x8 블록 퍼즐에 칩 x 배수 점수와 조커 빌드 로그라이크를 얹은 모바일 웹 퍼즐 게임.

플레이: https://kh32-7.github.io/block-joker/

## 원작 조합과 비튼 포인트
- Block Blast: 8x8 보드, 트레이 조각 3개, 가로/세로 줄 제거, 회전 없음
- Balatro: 앤티 1~8 x (스몰/빅/보스) 라운드, 칩 x 배수 점수, 조커 상점, 이자, 보스 저주
- 비튼 점: "핸드" 대신 "트레이"(조각 3개 묶음) 수가 자원. 조각에 박힌 보석(금/루비/유리/강철)이 카드 강화 역할을 하고, 보드 모양 자체(모서리, 전부 비우기, 남은 블록 수)가 조커 조건이 됨

## 조작법
- 트레이의 조각을 손가락으로 끌어서 보드에 놓기 (조각은 손가락보다 약 1.5칸 위에 뜸)
- 놓일 자리 고스트 미리보기와 지워질 줄 하이라이트 제공
- 조커 카드를 탭하면 설명, 라운드 이름을 탭하면 목표와 보스 정보
- 오른쪽 아래 버튼으로 일시정지(엄지 닿는 위치), 데스크톱은 마우스와 Esc 키 사용 가능
- 트레이 아래 "트레이 교체" 버튼: 라운드당 2번. 조각을 탭해 고르면 고른 조각만, 안 고르면 전부 새로 받음(트레이 수 소모 없음). 남은 교체 환급은 없음

## 핵심 시스템
- 점수: 칩 = 제거 칸 수 x 5 + 줄 종류 칩, 배수 = 줄 종류 배수 + 콤보. 줄 종류는 가로줄, 세로줄, 더블, 멀티, 십자 5종이고 줄 강화 카드(행성 대응)로 레벨업
- 연출: 칸 흰 플래시 후 1.2배 팽창과 파편, 여러 줄이면 보드 테두리 발광, 콤보 3 이상 펠트 파동, 줄마다 빛 줄기 스윕, 드래그 중 예상 점수 미리보기, 콤보 단계 문구(굿/그레잇/엑설런트/언빌리버블), 칩과 배수 박스가 합쳐지며 "칩 X 배수 = 점수" 공식 표시, 올 클리어 전용 폭발
- 비차단 점수 연출: 연출 중에도 다음 조각을 놓을 수 있고 점수는 큐로 이어서 재생, 빈 곳 탭으로 스킵, 속도 x1/x2/x4
- 콤보: 줄을 지운 배치가 이어지면 증가(유예 4배치), 보드 위 "콤보 N · 다음 +N 배수" 알약으로 상시 표시. 더블/멀티는 가로줄/세로줄 레벨 일부를 함께 받음
- 막힘 구제: 교체까지 다 쓰고 놓을 곳이 없으면 런당 1번, 앤티 x $5 와 보유 코인 40% 중 큰 금액 또는 조커 1장 희생으로 가장 꽉 찬 가로줄 3개를 비움. 앤티 1 스몰/빅은 놓을 수 있는 조각 보정 100%. 게임 오버 화면에 "N점 부족"과 팁 표시
- 보석: 금 +25 칩, 루비 +3 배수, 유리 x1.5 배수(25% 확률로 깨짐), 강철 보드에 있는 동안 줄 제거마다 x1.2
- 조커 72종(일반 31, 고급 23, 희귀 13, 전설 5). 빌드 축 5개(가로/세로/보석/콤보/교체): 같은 축 조커 2장 이상이면 조건을 만족한 제거에 시너지 배수(2장 x1.35 ~ 5장 x2.4). 수평/수직주의자 x2, 가로 군주/세로 제왕 x2.5, 교체 연계 조커 3종(재활용꾼, 고물상, 트레이더). 일반 조커의 고정 배수는 +2~3으로 낮춤. 에디션 4종(포일 +30 칩, 홀로 +6 배수, 폴리크롬 x1.5, 네거티브 슬롯 +1)
- 상점: 조커 3장(보유 조커와 같은 축이면 초록 테두리 + "시너지" 태그, 같은 축 등장 가중치 상승, 앤티마다 첫 상점에 미발견 조커 1장 확정), 카드 2장(줄 강화 가격 = $3 + 현재 레벨 / 보석 부여), 부스터 팩 2개, 특수 서비스 1개, 앤티당 바우처 1장. 앤티 4부터 희귀 확정 슬롯($12~15)과 에디션 부여($12) 상시. 리롤은 상점 안에서 누를 때마다 +$1. 카드/팩/바우처 줄은 가로 스크롤(오른쪽 페이드 + 화살표)
- 보스 저주 16종 + 앤티 8 쇼다운 보스 3종(배경 전환, 전용 BGM, 인트로), 보스마다 고유 칩 아이콘
- 조각 생성 보정: 놓을 수 있는 조각이 하나도 없으면 높은 확률로 하나를 교체
- 밸런스: `scripts/sim.mjs` 트레이 탐색 봇 400판 기준 "빌드 축 집중" 승률 11.5%(평균 앤티 4.9) vs "범용 조커만" 5.3%(평균 앤티 3.9)로 축 빌드가 약 2.2배 유리. 라운드당 사용 트레이 3.7~3.9, 앤티 1~3에서 한 방 최고 점수는 목표의 60~95%(한 방 클리어 억제). 앤티 1 스몰 목표 370
- 사운드: 레이어드 합성 효과음, 노이즈 임펄스 리버브, 마스터 컴프레서 + 리미터 + 소프트 클리퍼(피크 -3dBFS), 효과음별 게인을 오프라인 렌더 측정으로 정규화(주요 RMS -25~-20dB, 작은 효과음 -28~-24dB). 스테레오: 칩 왼쪽, 배수 오른쪽, 조커 발동은 슬롯 위치로 패닝, 칩은 2~5kHz 클릭 노이즈, 배수는 상승 스윕 노이즈 레이어, 피치 랜덤 ±5%. BGM은 150Hz 이하 사인 베이스, 두 옥타브 올린 코드 컴핑(좌우 분산), 1~3kHz 삼각파 플럭 + 핑퐁 딜레이, 7~10kHz 하이패스 하이햇/셰이커로 500Hz 이상 에너지 약 55%, 좌우 상관 약 0.58 (스모크에서 FFT 대역과 상관 측정). BGM 4곡 + 앤티에 따라 적층, 점수 연출 중 덕킹

## 장기 진행 (localStorage, 저장 버전 3 + 마이그레이션)
- 토큰: 런 종료 시 클리어 라운드, 보스, 승리, 난이도에 비례해 지급(포기는 보상 없음). 미션, 업적, 출석, 레벨 업으로도 획득
- 컬렉션: 처음엔 조커 14종만 상점에 등장. 토큰으로 나머지 조커 47종, 시작 덱 5종, 테마 스킨 4종 해금(전체 약 1,800 토큰, 20판 이상 분량). 조커 도감은 잠김/미발견 실루엣/발견 카드
- 난이도(스테이크) 5단계, 승리 시 다음 단계 해금, 단계별 기록과 덱 x 스테이크 승리 스티커
- 데일리: 날짜 시드 + 오늘의 규칙으로 하루 1회, 결과 공유 카드, 지난 7일 기록. 일일 미션 3개(자정 갱신), 주간 미션 3개와 주간 상자
- 7일 출석 캘린더(7일차 대형 보상, 첫 런 이후부터 표시). 미션/업적 보상은 직접 받기(토큰이 카운터로 날아감)
- 업적 27종(첫 판에 몰리지 않게 기준 상향), 프로필/통계 화면, 경험치 레벨
- 이어하기: 매 배치마다 보드, 트레이, 점수, 콤보, 조커 성장값을 저장하고 그대로 복원(되감기 불가)
- 온보딩: 첫 배치 손가락 안내, 첫 줄 제거 때 칩 X 배수 코치 마크, 첫 상점에서 조커 발동 순서 시연, 보스를 처음 만날 때 저주 설명 카드, 그림이 있는 4페이지 도움말

## 실행 / 빌드
```
npm install
npm run dev       # 개발 서버
npm run build     # dist/ 생성
npm run preview   # 빌드 결과 미리보기
npm run smoke     # Playwright 스모크 테스트 (빌드 후 실행, 스크린샷은 shots/, 포트 SMOKE_PORT 기본 4391, 전체 효과음 음량표와 4배 CPU 스로틀 드롭 성능 포함)
node scripts/sim.mjs 200 1 tray 1   # 밸런스 시뮬레이션 [판수] [구매 0/1/2] [배치 greedy/tray] [스테이크]
```

## 디버그 URL 옵션
- `?seed=문자열`: 시드 고정
- `?debug`: 목표 점수 대폭 감소, 시작 코인 +10, 토큰 x10, 테스트 훅 `window.__bj`, 사운드 계측 `window.__bjAudio.renderOffline(이름)`
- `?debug=hard`: 목표 점수 100배 (게임 오버 테스트용)
