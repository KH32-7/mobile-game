# 포켓 시즈 (Pocket Siege)

엘릭서 카드 실시간 2레인 대전에 같은 유닛 합성과 로그라이크 원정을 섞은 모바일 전략 게임.

플레이: https://kh32-7.github.io/pocket-siege/

## 원작 조합과 비튼 포인트

- **Clash Royale**: 세로 아레나, 강과 다리 2개, 킹 타워 1 + 프린세스 타워 2, 엘릭서 0~10, 손패 4장 + 다음 카드, 8장 덱 순환, 3분 + 연장전
- **Merge Tactics**: 필드 위 내 유닛에 같은 카드를 떨어뜨리면 새로 소환하지 않고 그 유닛이 레벨업 (최대 3성). 비용은 그대로라서 "새로 뽑을지, 키울지" 판단이 핵심
- **로그라이크 덱빌딩**: 10 스테이지 원정 지도, 갈림길(일반전/엘리트전/상점/휴식), 전투 후 카드 3장 중 선택 또는 유물, 킹 타워 HP 이월
- **장기 진행**: 영구 카드 컬렉션과 레벨업, 트로피 사다리와 아레나 5단계, 원정 난이도 5단계, 일일 미션/연속 출석/무료 상자, 업적 19개와 통계

## 조작법

- 하단 카드를 끌어서 내 진영에 놓으면 소환 (놓을 수 있는 곳 외에는 빨갛게 표시)
- 같은 카드를 내 유닛 위에 놓으면 합성 (금색 링과 "합성!" 표시)
- 카드를 탭해서 선택한 뒤 전장을 탭해도 소환 가능
- 주문 카드는 드래그 중 범위 원 표시, 적 진영 어디든 사용 가능
- 적 프린세스 타워를 부수면 그쪽 레인의 적 진영 일부까지 배치 구역 확장
- 좌상단 버튼 또는 ESC 로 일시정지, 데스크톱은 마우스로 동일하게 플레이

## 핵심 시스템

- **대전**: 타워 자동 공격, 킹 타워는 맞거나 프린세스 타워가 부서지면 기동. 킹 타워 파괴 즉시 승리, 3분 종료 시 크라운 수로 판정, 동점이면 1분 연장전(엘릭서 2배, 먼저 타워를 부수면 승리), 그래도 동점이면 무승부. 마지막 60초 엘릭서 2배
- **유닛**: 지상/공중, 건물만 노리는 유닛, 스플래시, 원거리 투사체, 겹침 방지 분리 스티어링, 다리로만 강 횡단, 건물 우회 이동
- **합성**: 2성 체력/공격력 x1.65, 3성 x2.5, 크기 증가 + 별 표시 + 번쩍 연출. 무리 카드(궁수, 고블린 등)는 함께 소환된 무리 전체가 레벨업
- **카드 20종**: 기사, 궁수 3인, 거인, 고블린 무리, 해골 떼, 마법사, 미니 드래곤, 폭탄병, 창기병(돌격), 대포, 치유 토템, 화염구, 번개, 얼음, 화살비, 골렘(사망 시 분열), 암살자(점멸), 총사, 박쥐 떼, 여전사
- **유물 12종**: 엘릭서 샘, 훈련 교본, 강철 성벽, 비전 두루마리, 치유의 인장, 연금술 플라스크, 파수꾼 깃발, 전쟁 북, 황금 왕관, 대장장이 망치, 수호 기사단, 가시 성벽
- **AI**: 엘릭서 관리, 공중엔 대공 유닛/떼엔 스플래시로 카운터, 탱커 뒤 지원 푸시, 합성 활용, 체력 낮은 타워 주문 마무리. 스테이지가 오를수록 반응 속도, 실수 확률, 덱 강도 상승. 10스테이지 보스는 거대 킹 타워(범위 포격) + 주기적 병력 소환
- **원정**: 시작 덱 8장, 덱 최대 12장(같은 카드 2장까지), 상점(카드/유물/성벽 보수/카드 제거), 휴식(회복 또는 카드 제거), 원정 중 앱을 닫아도 지도 기준 이어하기
- **메타 진행 (localStorage, 저장 버전 필드 + 마이그레이션)**
  - 카드 조각 + 코인으로 영구 레벨업 (최대 Lv.6, 레벨당 +8%), 미발견 카드는 실루엣 표시
  - 빠른 대전 승패로 트로피 증감, 아레나 5단계(풀밭 훈련장, 고블린 숲, 해골 협곡, 용암 요새, 얼음 왕좌)마다 배경색과 도달 보상(코인 + 신규 카드)
  - 원정 난이도 5단계(견습, 기사, 영웅, 전설, 신화), 클리어하면 다음 단계 해금, 적 강화 + 보상 배율 증가
  - 일일 미션 3개(자정 갱신), 연속 출석 보상, 3시간마다 무료 상자(실제 시간 기준)
  - 업적 19개, 통계 화면(총 승수, 한 판 최다 합성, 타워 파괴 수 등)

## 실행 / 빌드

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 생성
npm run preview  # 빌드 결과 확인
node scripts/smoke.mjs   # 빌드 후 Playwright 스모크 테스트 (PORT 환경변수로 포트 지정, 기본 4791)
```

디버그 URL 옵션

- `?debug`: 시간 3배속, 적 타워 HP 10%, 적 AI 반응 느림, FPS 표시
- `?speed=N`: 시간 배속 지정
- `?elixir`: 내 엘릭서 무한
- `?seed=N`: 원정 지도/대전 시드 고정
- `?stage=N`: 원정을 N 스테이지부터 시작
- `?notut`: 첫 전투 튜토리얼 생략

## 구조

- `src/config.js`: 카드, 타워, 유물, 스테이지, 메타 진행 밸런스 수치
- `src/battle.js`: 대전 시뮬레이션 (이동, 타기팅, 투사체, 주문, 합성, 판정)
- `src/ai.js`: 적 AI (팀 파라미터로 양쪽 모두 구동 가능)
- `src/render.js`, `src/icons.js`: 캔버스 렌더링과 절차적 아이콘
- `src/campaign.js`: 원정 지도 생성, 보상, 상점
- `src/meta.js`: 프로필 저장/마이그레이션, 컬렉션, 트로피, 데일리, 상자, 업적, 통계
- `src/audio.js`: WebAudio 효과음과 절차적 BGM
- `src/main.js`, `src/ui.js`: 화면 흐름, 입력, DOM 오버레이
