# 로그 퍼트 (Rogue Putt)

새총처럼 당겨 치는 탑다운 미니골프에 로그라이크 코스 생성, 유물 빌드, "타수 = 체력" 규칙을 합친 모바일 웹 게임임.

플레이: https://kh32-7.github.io/rogue-putt/

## 원작 조합과 비튼 포인트
- Angry Birds 식 새총 조작: 화면 어디서나 끌어서 당기고 놓으면 반대 방향으로 샷. 시작점 근처로 되돌리면 취소
- Golf Rival, Mini Golf King 계열 캐주얼 미니골프: 벽 반사, 모래, 물, 얼음, 경사, 범퍼, 풍차, 움직이는 벽, 워프, 부서지는 상자
- 로그라이크 비틀기: 매 런마다 시드 기반으로 새로 생성되는 18홀 코스, 홀마다 유물 3개 중 1개 선택, 파를 넘긴 타수만큼 하트가 깎이는 "스트로크 = 체력" 구조

## 조작
- 드래그 후 놓기: 샷 (당긴 길이 = 파워, 점선 = 최대 비거리의 40% 길이로 첫 반사까지만 보여줌. 정지 지점은 감으로 맞춤)
- 시작점으로 되돌리기: 샷 취소
- 전체 보기 버튼: 홀 전체 줌아웃 / 공 따라가기 전환
- 일시정지 버튼 또는 Esc: 일시정지 메뉴
- 유물에 따라 구르는 중 탭(스키 왁스), 더블탭(브레이크), 되돌리기 버튼(멀리건) 사용

## 핵심 시스템
- 한 런 = 전반 9홀 + 후반 9홀. 방 조각 템플릿(직선, 도그레그, 넓은 방, 갈림길, 기둥, 지그재그, 깔때기, 원형) 조합 후 요소 배치, 그리드 BFS 로 컵까지 경로 검증. 뒤로 갈수록 요소 증가
- 하트 5개로 시작. 홀이 끝날 때 파보다 많이 친 타수만큼 하트 감소(한 홀 최대 2), 파+3 에 도달하면 자동 기권. HUD 에 "파까지 N타" 예고. 컵 주변 점선 원(컨시드 거리) 안에 멈추면 1타를 더해 자동 홀아웃. 버디 이하면 코인과 하트 회복 기회. 하트 0 이면 런 종료(즉시 정산되어 새로고침으로 되살릴 수 없음)
- 첫 런 코치마크: 탭해야 닫히고 한 번에 하나씩, 1번 홀은 컵 스포트라이트 + 손가락 드래그 시범
- 파 산정: BFS 경로 구간 수, 경로 길이, 위험 요소로 기대 타수를 추정하고 물/가짜 컵/긴 경로처럼 변동이 큰 홀에 여유를 더함. 사람 근사 AI(샷 세기에 비례하는 조준/파워 오차) 자동 플레이로 보정. 티에서 컵이 일직선으로 보이는 홀은 기둥이나 범퍼를 강제로 배치하고, 티샷은 컵이 조금 더 엄격해서 홀인원이 드묾. verify-gen 이 파 대비 평균(+-0.5), 파 이하 비율(55~70%), 홀인원(5% 이하), +2 이상(10% 이하)을 2 표준오차 허용 범위로 검사
- 위기 보정: 파에 도달하면 컵과 컨시드 거리가 커짐. 물에 빠지면 벌타 +1 후 빠지기 직전 자리에서 다시 침
- 보스 홀: 6번 움직이는 컵, 12번 세 개의 컵(가짜는 깃발이 반대로 휘날리고 테두리에 금, 입장 직후 진짜 컵이 반짝임), 18번 거대 풍차 + 제한 시간. 보스 보상은 희귀 이상 확정
- 상점: 4, 9, 14번 홀 뒤에 등장. 코인으로 유물과 하트 구매
- 유물 40종 (일반/희귀/영웅 등급, 양날의 검 트레이드오프형 포함). 풀이 모자라면 보유 유물 강화(Lv2) 선택지가 나옴
- 태그 시너지: 같은 태그 2개면 1단계, 3개면 2단계 효과가 곱연산으로 쌓임 (예: 코인 x1.6 + 유리 공 x2 + 탐욕 x1.5 = 코인 4.8배 빌드, 범퍼 3개면 범퍼 파워 x1.35 와 범퍼 코인, 벽 3개면 반사 직후 가속)
  - 기본 19종: 끈끈이 공, 자석 컵, 긴 조준선, 바운스 킹, 모래 무시, 행운의 티, 에코 샷, 쇳덩이 공, 동전 자석, 당구 달인, 순풍, 멀리건, 깃털 공, 탱탱볼, 목수, 핀볼 마법사, 워프 전문가, 쌍둥이 동전, 컵 레이더
  - 해금 21종: 스키 왁스, 바람막이, 경사 타기, 구명조끼, 도박사의 컵, 브레이크, 수상 스키, 유리 공, 유령 공, 탐욕의 주머니, 역전의 명수, 하트 수확, 큰 컵, 홀인원 사냥꾼, 여분의 심장, 분열 샷, 거북이 등껍질, 보호막, 파 여유, 독수리 눈, 마지막 기회
- 자체 2D 물리: 원 vs 선분/원/사각형 충돌, 반발 계수, 지면별 마찰, 서브스텝 터널링 방지, 컵 흡입과 립아웃
- 비주얼 (2.5D): 공중에 뜬 섬 코스(측면 흙/돌 단면 + 블러 드롭 섀도), 높이 있는 블록 벽(윗면 하이라이트 + 2톤 앞면), 월드별 벽 재질(나무, 사암, 얼음, 네온), 페어웨이/러프 2단 잔디 + 캐시된 잔디결 텍스처, 컵 주변 원형 그린, 경사 명암, 입체 범퍼/풍차, 코스 밖 월드 장식, 조명 그라데이션과 비네트
- 사운드: 노이즈 버스트 + 레조넌트 밴드패스 타격음, 금속 모달 합성 컵 딸그락, 필터 스윕 물소리, 벽 재질별 충돌음, 피치/볼륨 랜덤화, 절차적 리버브(노이즈 임펄스 컨볼버) + 마스터 컴프레서, 지면별 구르는 소리, 월드별 BGM 4종 + 보스 변주, 조준 중 음악 필터 닫힘 / 컵 근처 긴장 / 결과 스팅어, 음악/효과음 개별 볼륨

## 장기 진행 (localStorage, 저장 버전 필드 + 마이그레이션)
- 테마 월드 4개(초원, 사막, 설원, 우주) 순차 해금. 월드마다 요소 구성과 색이 다름. 월드별 별 3개(전반 9홀, 완주, 파 이하 완주)와 최고 기록
- 런 종료 시 보석 획득. 보석으로 잠긴 유물 21종 해금, 공 스킨, 트레일, 깃발, 시작 유물 선택 특전 구매 (첫 해금 3~4런, 전체 해금 20런 이상 기준)
- 유물 도감 (미발견은 실루엣)
- 데일리 코스(날짜 시드, 모두 같은 코스), 결과 이모지 스코어카드 복사, 일일 미션 3개(자정 갱신) + 3개 완료 보너스 상자, 7일 출석 달력
- 업적 21개, 통계 화면, 최근 20런 히스토리
- 시즌 트랙 30단계: 홀 클리어, 버디, 별, 미션, 출석으로 경험치. 레벨마다 보석, 10/20/30 레벨에 시즌 한정 깃발/공/트레일
- 이어하기: 샷마다 타수, 하트, 공 위치, 상자/코인 상태를 저장해서 앱을 닫아도 그 상태 그대로 재개 (새로고침으로 하트를 되돌릴 수 없음)

## 보석 경제 시뮬레이션
`node scripts/econ-sim.mjs` 가 실제 정산 코드(meta.js)로 "하루 2런, 매일 출석, 이틀에 미션 1개" 플레이어를 돌린 결과 (시즌 보상 제외)

| 런 | 클리어 홀 | 이번 런 보석 | 누적 보석 (업적/출석/미션 포함) |
|---|---|---|---|
| 1 | 5 | +1 | 3 |
| 2 | 6 | +2 | 8 |
| 3 | 7 | +2 | 12 |
| 5 | 9 | +6 | 30 |
| 10 | 13 | +6 | 74 |
| 20 | 18 | +14 | 229 |
| 30 | 18 | +14 | 409 |
| 40 | 18 | +14 | 584 |

- 가장 싼 유물(12)은 3런째 해금 가능, 전체 해금(유물 + 꾸미기 + 특전 합계 1095)은 40런 이상
- 데일리 보석은 하루 첫 런만, 데일리 보너스와 "데일리 완료" 미션은 9홀 이상 클리어 시에만 인정

## 실행 / 빌드
```bash
npm install
npm run dev        # 개발 서버
npm run build      # dist/ 생성
npm run preview    # 빌드 결과 미리보기
npm run verify-gen # 생성기 검증 (시드 240개 x 월드 4개 x 18홀 BFS + 물리 자동 플레이)
npm run smoke      # Playwright 스모크 테스트 (build 후 실행, 스크린샷은 shots/)
node scripts/econ-sim.mjs # 보석 경제 시뮬레이션 표
```

URL 옵션: `?seed=숫자`, `?debug` (자동 조준 샷, 즉시 홀인, 하트 감소 버튼), `?hearts=1`, `?hole=6`, `?world=snow` (debug 전용)
