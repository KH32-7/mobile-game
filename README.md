# 보이드 모 (Void Maw)

도시 바닥에 뚫린 블랙홀이 되어 모든 걸 삼키며 청소 로봇 군단에게서 5분을 버티는 3D 액션 로그라이트임.

플레이: https://kh32-7.github.io/void-maw/

## 원작 조합과 비튼 포인트

- **Hole.io / All in Hole**: 홀보다 작은 물체는 가장자리에서 기울며 구멍 속으로 떨어지고, 삼킬수록 홀이 커짐.
- **Survivor.io / Vampire Survivors**: 끝없이 몰려오는 적 웨이브, 레벨업 시 스킬 카드 3장 중 택 1, 스킬 조합 진화.
- **비튼 점**: 적도 "크기"로 싸움. 홀보다 작은 로봇은 그냥 삼켜지고, 큰 로봇은 테두리에 닿으면 피해를 줌. 스킬로 때리면 적이 쪼그라들어 결국 삼킬 수 있게 됨. 보스 "거대 청소 메카"는 HP에 비례해 크기가 줄어들고, 홀보다 작아진 순간 삼켜야만 클리어됨.

## 조작

- 화면 아무 곳이나 누르고 드래그: 누른 위치에 떠오르는 가상 조이스틱으로 이동
- 손을 떼면 서서히 멈춤
- 데스크톱: 마우스 드래그 또는 WASD / 방향키

## 핵심 시스템

- **진짜 구멍 표현**: 바닥 셰이더(onBeforeCompile)에서 홀 원 안쪽을 discard 하고, 아래에 안쪽 면만 그리는 원통 우물(아래로 갈수록 검정)을 둬서 떨어지는 물체가 실제로 구멍 안으로 들어가 보임. 테두리는 은은한 글로우 링.
- **성장**: 삼킨 물체 면적만큼 홀 면적 증가, 크기 단계 돌파 시 SIZE UP 연출과 카메라 펀치, 카메라가 부드럽게 줌아웃.
- **카메라**: 66도 틸트, 세로 화면 aspect 에 맞춰 거리를 계산해 홀이 화면 폭의 약 10~30% 로 유지됨. 홀을 가리는 건물은 높이를 눌러 보여주고, 홀 테두리는 깊이 무시 실루엣으로 한 번 더 그림
- **먹을 수 있음 표시**: 삼킬 수 있는 적/큰 소품은 홀 색 바닥 링, 위험한 적은 붉은 링. 화면 밖의 먹을 만한 큰 물체(또는 삼킬 수 있게 된 보스)는 가장자리 화살표로 안내
- **적 6종**: 청소봇(근접), 돌진봇(돌진), 투척봇(쓰레기 투척, 착탄 지점 경고), 거대 청소기(탱커), 미니보스 청소 트럭 대장(2분 30초), 보스 거대 청소 메카(5분, 내려찍기와 졸개 소환).
- **스킬 12종 (각 최대 5레벨)**: 파편 위성, 역류 캐논, 중력 펄스, 사건의 지평선, 폭식, 가속, 재생, 블랙 번개, 웜홀 대시, 초신성, 톱니 테두리, 탐욕
- **진화 7종 (무기 Lv5 + 짝 패시브 보유)**: 강착 원반 (파편 위성 + 사건의 지평선), 특이점 포 (역류 캐논 + 폭식), 폭풍 번개 (블랙 번개 + 가속), 흡혈 톱니 (톱니 테두리 + 재생), 중력 붕괴 (중력 펄스 + 사건의 지평선), 황금 초신성 (초신성 + 탐욕), 차원 균열 (웜홀 대시 + 가속). 12개 스킬이 모두 재료로 쓰이고, 카드에 진화 재료 아이콘 표시. 가진 무기의 짝 패시브가 더 자주 나오는 가중치로 빌드 방향이 생김. 진화 가능 카드는 무지개 테두리와 전용 연출
- **보스전**: 보스는 등장 시 홀 반지름의 1.6배(최소 11), 미니보스는 1.3배(최소 5) 크기로 화면 좌우 끝 바로 밖에 등장. 보스는 HP를 70% 이상 깎아야 홀보다 작아짐. 삼킬 수 없을 땐 붉은 화살표 + 남은 거리, 삼킬 수 있으면 금색 화살표. 격파 후 3초간 반경이 급팽창하며 블록째 빨려드는 피날레 와이드 샷
- **후반**: 240초 이후 성장 감쇠가 풀려 반지름 12~14 까지 커지며 도시를 통째로 삼킴
- **HUD**: 레벨바 옆 스탯 칩, 보스전엔 HP 바 자리가 보스 바로 바뀌고 HP 는 작은 칩으로 (상단 약 100px). 콤보는 우상단 작은 카운터, 10 단위에서만 크게
- **사운드**: 삼키기 팝은 크기별 저역 레이어 + 250~800Hz 배음 + 피치 랜덤, 큰 물체는 서브 "쿵"과 럼블, 노이즈 임펄스 ConvolverNode 리버브, 컴프레서 + 리미터 마스터, 16마디 편곡 BGM (1~3kHz 리드, 카운터 멜로디, 섹션별 드럼 변주, 60초 드럼 필, 150초 미니보스 스팅어, 240초 템포 +8, 일반/보스/레벨업 전환과 덕킹), 적 삼킴 전용 금속성 "끼익 꿀꺽", 결과 화면 코인 틱, 배경음/효과음 개별 볼륨
- **필**: 크기별 팝 사운드와 콤보 피치 상승, 콤보 카운터("x12 냠냠!"), 피격 흰색 플래시, 데미지 숫자, 처치 파티클, 붉은 비네트, 화면 흔들림, 히트스톱, 햅틱

## 장기 진행 (전부 localStorage, 저장 버전 필드 + 마이그레이션)

- **맵 3종 순차 해금**: 파스텔 시티 → 선샤인 비치(바다, 파라솔, 튜브, 매점, 보트, 호텔) → 러스티 팩토리(작업자, 컨테이너, 사일로, 굴뚝). 맵마다 소품 크기 사다리, 적 구성, 적 장식(밀짚모자/안전모), 보스 이름과 색이 다름
- **맵별 난이도 1~5**: 클리어하면 다음 난이도 해금, 맵별 최고 기록 저장
- **영구 강화 트리 3단계 9종**: 최대 HP, 중력 장갑, 시작 크기 / 이동 속도, XP, 스킬 위력 / 코인, 카드 재추첨, 재탄생(부활). 2단계는 1단계 합계 Lv 10, 3단계는 2단계 합계 Lv 12 필요
- **스킬 연구소**: 처음엔 스킬 7종만 등장, 나머지 5종은 코인으로 해금
- **홀 스킨 7종**: 보이드, 네온 시안, 벚꽃, 용암, 독성, 황금, 은하 (코인 구매 또는 업적/출석 보상)
- **데일리**: 자정에 갱신되는 일일 미션 3개 + 전부 완료 보너스, 7일 주기 연속 출석 보상, 날짜 시드 데일리 챌린지(맵 + 변형 규칙)
- **업적 22종**과 통계 화면 (총 삼킨 수, 총 처치, 최장 생존, 최대 크기 등)
- 타이틀에 코인, 출석 일수, 미션/업적/스킨 알림 뱃지, 새 맵 NEW 표시
- 첫 실행은 타이틀 없이 바로 3단계 튜토리얼 런 (작은 것 3개 먹기 → 보라 링 청소봇 삼키기 → 빨간 링 로봇 5초 피하기, 단계별 손가락/화살표 안내), 출석 보상은 첫 판 결과 뒤부터
- 데일리 챌린지는 해금된 맵에서만 나옴
- 저장 데이터가 손상되면 백업(void-maw-save-bak)에서 복원하고 알림, 백업도 실패하면 "저장 데이터를 복구하지 못함" 알림
- 결과 화면: 숫자 카운트업, 코인이 지갑으로 날아가는 연출, 다음 강화까지 남은 코인 진행 바

## 밸런스 목표와 검증

합격 기준은 사람 반응 속도를 흉내 낸 봇임. `scripts/balance.mjs` 는 requestAnimationFrame 을 1/60초 고정 스텝 가상 시간으로 돌리고, 게임의 실제 Input 핸들러에 포인터 이벤트를 보내 조작함. 기본값은 12프레임(0.2초)마다 한 번 판단, 조이스틱 85%, 카드 무작위. 판이 끝날 때마다 번 코인으로 가장 싼 강화를 사서 다음 판을 진행하고, 피해원(투척, 거대 청소기, 미니보스 등)을 판별로 기록함.

```bash
npm run build
node scripts/balance.mjs 3 casual            # 캐주얼: 0.2초 반응, 조이스틱 0.85, 무작위 카드
node scripts/balance.mjs 1 casual --upg=10   # 강화 10레벨을 미리 사고 시작
REACT=6 MAG=1 node scripts/balance.mjs 2 skilled
```

| 항목 | 목표 | 최근 측정 |
| --- | --- | --- |
| 캐주얼 봇, 강화 0 생존 | 150~180초 | 166초 |
| 캐주얼 봇, 강화 10 생존 | 240초 안팎 | 227초, 322초 (강화 11, 보스전 도달) |
| 숙련 봇 (0.1초 반응) | 보스전 도달, 강화 후 클리어 | 강화 0: 318초 보스전 사망, 강화 10: 323초 클리어 |
| 보스를 삼킬 때 남은 HP | 30% 이하 (70% 이상 깎아야 함) | 32% |
| 미니보스 | 등장 즉시 삼킬 수 없음 | 등장 14~17초 뒤 삼킬 수 있게 됨 |
| 반지름 60초 / 300초 | 약 3 / 12~14 | 3.1~4.3 / 8.7~14.6 |
| 5분 시점 레벨, 카드 선택 | Lv 20 이상, 18회 이상 | Lv 23~27, 23~26회 |
| 적 최대 수 / 화면 안 비율 | 상한 120 / 70% 안팎 | 65~103 / 65~75% |

주요 피해원은 투척봇 착탄. 60~130초 구간 피해를 줄이려고 투척봇은 85초, 거대 청소기는 130초부터 등장하고, 착탄 피해의 크기 배율은 1.2 로 제한함. HP 30% 이하에서는 무적 시간이 1.2초에서 1.8초로 늘어남.

사운드 믹스 기준 (스모크에서 OfflineAudioContext 로 렌더해 계측): 마스터 피크 약 -3dBFS, 주요 효과음 RMS -24~-20dB 근처, 모든 효과음 -35dB 이상, BGM 150Hz 이하 에너지 35% 이하 (측정 14~19%), 처치음 RMS 약 -25dB.

## 실행 / 빌드

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 생성
npm run preview  # 빌드 결과 미리보기
npm run smoke    # 빌드 후 실행: Playwright 스모크 테스트 (shots/ 에 스크린샷)
```

### 디버그 URL 옵션

- `?debug` : `window.__game` 노출 (debugBoss, debugHitBoss, debugKill, debugGrow, debugXp, debugCoins)
- `?debug&t=290` : 경과 시간을 지정해 시작
- `?debug&speed=4` : 시간 가속 (프레임당 여러 번 업데이트)
- `?debug&god` : 무적
- `?debug&lvl=8` : 무작위 스킬 8회 획득 상태로 시작
- `?debug&norender` : 30프레임마다 한 번만 렌더 (밸런스 봇용)
- `?debug&title` : 첫 실행이어도 튜토리얼 런 대신 타이틀로 시작
- `?seed=123` : 도시 배치 시드

## 기술

- Vite 8 + 바닐라 JS + three.js, 모든 그래픽은 코드로 생성 (로우폴리 지오메트리, CanvasTexture 바닥)
- 소품과 적은 InstancedMesh, 파티클은 Points 풀, 그림자는 블롭 섀도
- 사운드는 WebAudio 합성 효과음 + 절차적 BGM
