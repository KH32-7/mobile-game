# 스웜 서퍼 (Swarm Surfers)

젤리 무리를 이끌고 3레인 트랙을 질주하며 숫자 게이트로 무리를 불리고, 적 무리와 요새를 머릿수로 밀어붙이는 3D 엔드리스 러너임.

플레이: https://kh32-7.github.io/swarm-surfers/

## 원작 조합과 비튼 포인트

- **Subway Surfers**: 3레인 스와이프 러너, 점프/슬라이드, 기차와 바리케이드, 파워업, 미션 배수 구조
- **Mob Control / Count Masters**: 수학 게이트(+10, x2, -8, ÷2)로 군중 불리기, 적 군중과 1:1 상쇄, 성문 체력만큼 돌진하는 요새
- **비튼 점**: 혼자가 아니라 무리 전체가 달림. 무리는 레인보다 넓게 퍼지고 레인을 바꾸면 꼬리처럼 따라와서, 장애물에 닿은 멤버만 튕겨 나감. 좁은 틈 앞에서 무리를 한 레인에 모으는 것(슬라이드로 폭 좁히기)이 핵심 스킬. 점프도 무리가 파도처럼 시차를 두고 뜀

## 조작법

| 입력 | 모바일 | 데스크톱 |
| --- | --- | --- |
| 레인 이동 | 좌/우 스와이프 | 방향키 좌우, A/D |
| 점프 (파도 점프) | 위로 스와이프 | 위 방향키, W, 스페이스 |
| 슬라이드 (무리 납작하게 뭉침) | 아래로 스와이프 | 아래 방향키, S |
| 일시정지 | 우상단 버튼 | Esc, P |

## 핵심 시스템

- **첫 판 튜토리얼**: 처음 켜면 메뉴 없이 바로 달리기. 15명으로 시작하고 튜토리얼 동안 피해 없음. 기차/바리케이드/차단봉 앞 8m 에서 시간이 0.2배로 느려지고 손가락 애니가 나오며, 맞는 스와이프를 하면 정상 속도. 마지막에 x2 게이트와 작은 적 무리 격파 체험
- **무리 시뮬레이션**: 리더 x 좌표 이력을 따라가는 꼬리 추종 + 해바라기 배치 슬롯 스프링. InstancedMesh 로 최대 200명 표시, 그 이상은 숫자만 증가하고 대표 인원이 여러 명 몫을 함
- **충돌**: 멤버별 AABB 판정. 리더가 맞으면 가장 앞의 멤버가 새 리더가 됨. 장애물 하나가 지울 수 있는 인원은 max(3, 25%) 까지이고 초과분은 튕겨 비틀거리며 버팀. 인원 0 이면 게임 오버
- **입력 보정**: 점프는 착지 직전 입력을 버퍼링. 게이트는 목표 레인 기준으로 통과 순간에 판정하고, 직전에는 무리 전체를 그 게이트 쪽으로 흡착해서 꼬리까지 같은 게이트를 지남
- **실력 보상**: 통과 0.3초 안에 레인을 바꿔 이득 게이트를 잡으면 아슬아슬 +10%, 장애물을 손실 없이 연속 통과하면 콤보로 거리 점수 배수 상승, 슬라이드로만 지나가는 좁은 틈 뒤 보너스 게이트, 콘밭을 뚫어야 하는 위험 레인에만 큰 보상이 있는 분기 청크
- **게이트**: 파랑=이득, 빨강=손해. 손해 게이트는 통과 직전 인원의 50% 까지만 잃고, 인원 200 이상이면 ÷3 이 나오지 않음. 0~300m 에는 나누기 게이트 없음, 구간마다 700~950m 에 좋은 게이트 줄 1개 보장. x2/x3 통과 시 짧은 슬로우와 큰 숫자 스탬프, 새 멤버는 게이트 뒤에서 튀어나와 합류
- **적 무리**: 한 레인만 막아서 피할 수 있음. 조우 30m 전에 현재 인원 기준으로 크기가 정해지고, 내 인원의 70% 를 넘으면 라벨이 빨갛게 깜빡이며 피하라고 알려줌. 부딪히면 서로 파고드는 푸시 후 1:1 상쇄, 상쇄된 캐릭터는 튕겨 나가고 전멸시키면 격파 스탬프와 코인 분수
- **전투 참여**: 적 무리 전투와 요새 돌격 중 화면을 탭 연타하면 돌격 속도가 최대 2배
- **적 무리**: 옆으로 겹치면 전투 돌입, 1:1 상쇄 (파티클 + 연속 뿅 소리)
- **파워업**: 자석, 방패(장애물 1회 파괴), 슈퍼점프 부츠(기차도 넘음), 확성기(주변 코인이 멤버로)
- **요새**: 1000m 마다 등장. 성문 체력은 진입 인원의 40~70% 로 정해지고 그만큼 멤버가 돌진해 소모됨. 격파 시 성벽 붕괴 후 성문 뒤 보너스 계단(x1 ~ x5, 첫 칸은 항상 도달)을 무리가 오르며, 인원이 많을수록 높은 층에 도달해 배수만큼 코인을 받음. 남은 인원은 그대로 다음 구간으로 이어지고, 다음 구간은 속도 상승과 더 어려운 패턴
- **점수**: 거리 점수(거리 x 미션 배수) + 무리 점수(요새 격파 시 남은 인원 x 구간 x 10). 결과 화면에서 따로 표시
- **절차적 트랙**: 패턴 청크 19종을 난이도 곡선에 따라 조합 (게이트/보너스 슬롯과 장애물/적 슬롯 번갈아 배치). 구간마다 테마 변경 (도시, 사막, 설원, 네온, 정글)

## 장기 진행 (전부 localStorage, 저장 버전 필드 + 마이그레이션)

- **재화**: 코인(업그레이드), 보석(희귀 재화. 보너스 계단 x3 이상 도달, 미션 배수 짝수 레벨, 업적, 출석, 주간 챌린지로 획득), 스킨 조각(요새, 미션 완료, 출석)
- **영구 업그레이드 4종**: 시작 인원, 자석 지속, 방패 확률, 게이트 행운 (여러 레벨)
- **스킨 컬렉션 9종**: 리더 모자와 무리 색이 바뀌고 각자 작은 패시브 보너스 (코인 +10%, 시작 인원 +4, 요새 보상 +30% 등). 컬렉션 화면에 3D 회전 미리보기. 보석 10~50개(구매 확인 단계 있음) 또는 조각 10개로 해금, 조각을 모아 최대 Lv.5 까지 레벨업하면 보너스 증가
- **시작 테마 선택**: 각 테마에서 요새를 3개 부수면 그 테마를 시작 테마로 선택 가능
- **미션 배수**: 미션 3개 동시 진행, 완료하면 새 미션으로 교체. 3개 완료마다 배수 상승 (거리 점수 = 거리 x 배수 x 콤보), 목표는 레벨마다 약 1.6배
- **일일 미션 3개 + 7일 연속 출석 보상**
- **주간 챌린지**: 주 번호 시드로 모두 같은 코스, 목표 거리 달성 시 보석 +2
- **업적 20개** (각 보석 1), **통계 화면** (총 거리, 판 수, 최대 인원, 격파 요새, 적, 코인, 플레이 시간 등)
- **부활**: 전멸 시 보석으로 무리 10명 + 방패 부활. 한 판에 여러 번 가능하고 비용은 1, 2, 4, 8 로 증가
- **사운드**: 타이틀 전용 루프와 테마별 BGM 변주 5종 (8마디 A/B 구성, 필인, 스테레오 아르페지오와 핑퐁 딜레이, 저역 셸프 컷, 구간 전환 1마디 크로스페이드). 효과음은 노이즈 임펄스 리버브, 금속 모달 코인, 화음 아르페지오 게이트, 럼블과 파편 클릭 요새 붕괴, 속도 비례 바람 루프. 일시정지/부활 대기/게임 오버에서는 로우패스 + 볼륨 30% 덕킹. 배경음과 효과음 따로 끄기
- **정보 위계**: 신규 유저 타이틀은 시작 버튼 위주로 단순하게 두고 판 수에 따라 기록, 업그레이드, 컬렉션, 업적, 주간 챌린지, 테마가 NEW 표시와 함께 차례로 열림. 빨간 점은 실제 행동 가능한 항목 최대 2개. 일시정지 해제 시 3, 2, 1 카운트다운
- 타이틀에 재화, 미션 배수와 진행도, 출석 보상, 주간 챌린지, 해금 가능 알림 점을 표시

## 실행 / 빌드

```bash
npm install
npm run dev       # 개발 서버
npm run build     # dist/ 생성
npm run preview   # 빌드 결과 확인
npm run build && node scripts/smoke.mjs   # 스모크 테스트 (shots/ 에 스크린샷)
```

스모크 테스트는 설치된 Chromium (`/opt/pw-browsers/chromium`, 환경변수 `CHROMIUM` 으로 변경 가능) 을 390x844 터치 모드로 띄워서 첫 실행 튜토리얼의 실제 스와이프(레인/점프/슬라이드), 게이트 인원 변화, 탭 전투, 일시정지 카운트다운, 부활, 게임 오버, 결과창 위 상점 표시, 요새 격파와 보너스 계단, 요새 후 인원 유지, 업그레이드/스킨 해금(구매 확인) 후 새로고침 유지, 이전 저장 데이터 마이그레이션, 작은/큰 화면의 부활 버튼 배치까지 확인함.

## 디버그 URL 옵션

- `?debug` FPS/드로우콜 표시
- `?god` 장애물 무적
- `?start=820` 시작 거리, `?count=120` 시작 인원, `?seed=7` 코스 시드
- `?fast=2` 시뮬레이션 배속, `?speed=0.8` 달리기 속도 배율, `?forthp=0.5` 요새 체력 배율
- `?chunks=enemySmall,gate3` 청크 강제 순환, `?norevive` 부활 제안 끔, `?notut` 첫 실행 튜토리얼 건너뜀

## 구조

- `src/main.js` 진입점, 루프 / `src/game.js` 게임 규칙 / `src/swarm.js` 무리 시뮬레이션
- `src/entities.js` 장애물, 게이트, 코인, 파워업, 적, 요새 / `src/chunks.js` 패턴 청크와 생성
- `src/world.js` 렌더러, 카메라, 트랙, 배경, 테마 / `src/chars.js` 캐릭터 인스턴싱(몸통, 눈과 무늬, 팔다리), 스킨 모자 / `src/preview.js` 컬렉션 3D 미리보기
- `src/fx.js` 파티클, 팝업 / `src/ui.js` 화면 UI / `src/audio.js` 효과음과 BGM 합성
- `src/data.js` 저장, 마이그레이션, 미션, 업적 / `src/config.js` 밸런스 수치
