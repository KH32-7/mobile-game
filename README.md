# 블록 조커 (Block Joker)

8x8 블록 퍼즐에 칩 x 배수 점수와 조커 빌드 로그라이크를 얹은 모바일 웹 퍼즐 게임.

플레이: https://kh32-7.github.io/block-joker/

## 원작 조합과 비튼 포인트
- Block Blast: 8x8 보드, 트레이 조각 3개, 가로/세로 줄 제거, 회전 없음
- Balatro: 앤티 1~8 x (스몰/빅/보스) 라운드, 칩 x 배수 점수, 조커 상점, 이자, 보스 저주
- 비튼 점: "핸드" 대신 "트레이"(조각 3개 묶음) 수가 자원. 조각에 박힌 보석(금/루비/유리/강철)이 카드 강화 역할을 하고, 보드 모양 자체(모서리, 전부 비우기, 남은 블록 수)가 조커 조건이 됨

## 조작법
- 트레이의 조각을 손가락으로 끌어서 보드에 놓기 (조각은 손가락보다 약 1.5칸 위에 뜸)
- 놓일 자리 고스트 미리보기와 지워질 줄 하이라이트 제공
- 조커 카드를 탭하면 설명, 라운드 이름을 탭하면 목표와 보스 정보
- 왼쪽 위 버튼으로 일시정지, 데스크톱은 마우스와 Esc 키 사용 가능

## 핵심 시스템
- 점수: 칩 = 제거 칸 수 x 5 + 줄당 10, 배수 = 1 + (동시 제거 줄 수 - 1) + 콤보. 조각 배치만으로도 칸 수만큼 소량 점수
- 콤보: 줄을 지운 배치가 이어지면 증가, 3번 연속 못 지우면 끊김
- 보석: 금 +25 칩, 루비 +3 배수, 유리 x1.5 배수(25% 확률로 깨짐 이펙트), 강철 보드에 있는 동안 줄 제거마다 x1.2
- 조커 26종 (슬롯 5, 왼쪽부터 순서대로 발동, 상점에서 순서 변경과 판매 가능). 성장형, 경제형, 보석형, 줄 모양형 등 시너지 설계
- 보스 저주 8종: 봉인된 심장, 안개 딜러, 거인의 손, 수평선, 빈털터리, 끊어진 사슬, 잔해 더미, 조커 봉인
- 상점 보상: 블라인드 기본 보상 + 남은 트레이 x $1 + 이자($5당 $1, 최대 $5), 리롤 가능
- 조각 생성 보정: 놓을 수 있는 조각이 하나도 없으면 높은 확률로 하나를 교체
- 앤티 8 보스 클리어 시 승리, 이후 엔드리스 진행 가능

## 장기 진행 (localStorage, 저장 버전 필드 + 마이그레이션)
- 토큰: 런 종료 시 클리어 라운드, 보스 격파, 승리, 난이도에 비례해 지급. 미션, 업적, 출석, 레벨 업으로도 획득
- 컬렉션: 처음엔 조커 12종만 상점에 등장. 토큰으로 나머지 조커, 시작 덱 6종, 테마 스킨 5종 해금. 조커 도감은 잠김/미발견 실루엣/발견 카드로 표시
- 난이도(스테이크) 5단계: 화이트, 레드, 그린, 블랙, 골드. 승리하면 다음 단계 해금, 단계별 최고 기록 저장
- 데일리: 날짜 시드 데일리 런 하루 1회, 일일 미션 3개(자정 갱신), 연속 출석 보상
- 업적 22종, 프로필/통계 화면(플레이 수, 최고 한 방, 최고 라운드 점수, 제거 줄 수 등), 경험치 레벨
- 이어하기: 라운드 시작 시점과 상점 상태를 저장해서 앱을 닫아도 이어서 플레이

## 실행 / 빌드
```
npm install
npm run dev       # 개발 서버
npm run build     # dist/ 생성
npm run preview   # 빌드 결과 미리보기
npm run smoke     # Playwright 스모크 테스트 (빌드 후 실행, 스크린샷은 shots/)
node scripts/sim.mjs 40 1   # 밸런스 시뮬레이션 (탐욕 봇, 1 = 조커 구매)
```

## 디버그 URL 옵션
- `?seed=문자열`: 시드 고정
- `?debug`: 목표 점수 대폭 감소, 시작 코인 +10, 토큰 x10, 테스트 훅 `window.__bj`
- `?debug=hard`: 목표 점수 100배 (게임 오버 테스트용)
